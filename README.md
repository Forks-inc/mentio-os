# Ágora

Inteligencia política para equipos de campaña. Ágora ayuda a medir y priorizar la conversación pública sobre candidaturas, adversarios y temas de agenda mediante métricas de participación de voz, sentimiento, relevancia e intención.

## Probar la aplicación

```bash
npm install
npm run demo
```

Para iniciar la aplicación en modo desarrollo:

```bash
npm run dev
```

## Desarrollo

- `npm run typecheck`: revisa los tipos de TypeScript.
- `npm run build`: genera la aplicación para producción.
- `npm run start`: inicia la aplicación compilada.

La marca y la descripción se configuran en `src/brand.config.ts`. La licencia del proyecto es MIT.
